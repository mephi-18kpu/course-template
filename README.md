# Название курса

Учебный репозиторий курса «Название курса» организации [`mephi-18kpu`](https://github.com/mephi-18kpu).

- Ответственный преподаватель: `@username`
- Учебный период: `20XX/20XX, осенний/весенний семестр`
- Учебные группы: `группа-1`, `группа-2`
